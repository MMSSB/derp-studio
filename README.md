**Derp Studio** is a sleek, single-page web application that allows users to generate, customize, and export unique monochrome-themed avatars. Built entirely with vanilla web technologies, it features a glassmorphism UI, a massive library of 150+ SVG assets, and a fully responsive mobile-first design.

---

## ✨ Features

* **Massive Asset Library:** Mix and match from over 150+ carefully crafted SVG assets across 6 categories:
  * 🧢 Headwear
  * 😃 Faces
  * 👕 Bodies
  * 🪄 Items
  * 🕶️ Eyewear
  * 🐱 Pets
* **Advanced Color Controls:** Customize the Canvas (Background), Skin, Primary, and Accent colors.
* **Randomize Chaos:** A built-in dice-roll feature that instantly generates a completely random avatar with a coordinated grayscale palette.
* **High-Res Export:** Download your masterpiece as a 1200x1200px PNG with a single click.
* **Fully Responsive:** Features a dynamic desktop workspace and a buttery-smooth bottom-sheet UI for mobile users.
* **No Dependencies:** Built with 100% vanilla HTML, CSS, and JavaScript. No build tools or frameworks required.
